# Aerospace Simulations Portfolio

A collection of physics engines and flight trajectory models developed in Python using NumPy and Matplotlib. 

## Project Highlights

### 1. Rocket Calculus Engine (`rocket_calculus.py`)
* **Objective:** Applied numerical differentiation to discrete time/altitude vectors.
* **Physics Concepts:** Calculates instantaneous velocity ($v = \frac{ds}{dt}$) and multi-stage acceleration profiles ($a = \frac{dv}{dt}$).

### 2. Multi-Angle Trajectory Variant (`rocket_angle_sim.py`)
* **Objective:** Simulates parabolic flight vectors using loops and trigonometric vector splitting.
* **Physics Concepts:** Explores downrange landing variances across $30^\circ$, $45^\circ$, and $60^\circ$ launch paths.

## Tech Stack
* **Language:** Python 3
* **Libraries:** NumPy, Matplotlib
